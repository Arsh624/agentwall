# agentwall v0.2 security Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop four more published MCP attacks (tool poisoning, tool shadowing, terminal escapes, egress to unlisted hosts) and make the audit log tamper-proof against forged chains.

**Architecture:** Each defence lives in the package that already owns that concern: `detect` scores, `pin` stores trust, `vault.Redactor` cleans strings, `policy` decides calls, `audit` signs entries. `firewall` wires them into the existing hooks. No new packages, no new dependencies.

**Tech Stack:** Go 1.2x std lib (`crypto/hmac`, `net/url`, `regexp`), existing deps only.

Spec: `docs/superpowers/specs/2026-11-21-v0.2-security-design.md`. Branch: `v0.2-security`. Run tests with `go test ./...`. On this Windows box write Go files with the Write/Edit tools, not shell heredocs (they mangle backslashes).
